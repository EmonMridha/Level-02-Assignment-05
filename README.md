## 📖 Overview

RentNest is a modern property rental web application where users can browse available properties, view detailed information, and manage property listings. Authenticated users can add, update, and delete their own properties, making it a complete rental management platform.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/EmonMridha/Level-02-Assignment-05
```

### 2. Go to the project directory

```bash
cd your-repository
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
pnpm install
```

### 4. Create an environment file

Create a `.env.local` file in the project root and add the required environment variables.

```env
NEXT_PUBLIC_API_URL=https://assignment-04-orpin.vercel.app/
```

### 5. Start the development server

```bash
npm run dev
```

or

```bash
pnpm dev
```

### 6. Open the application

Visit:

```
http://localhost:3000
```
